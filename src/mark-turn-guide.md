# Mark Turn Guide

Game 1 is the information game. If you can see Mark's four before locking yours, use the table below. If you only see his six, use the blind four unless Shuckle is in the six and you expect hazards. If you must lock blind, bring **Tyranitar / Sableye / Scizor / Gardevoir**.

## Which four to bring

| Mark's four includes      | Bring                                 | Lead                                                             |
| ------------------------- | ------------------------------------- | ---------------------------------------------------------------- |
| Ninetales + Shuckle       | Tyranitar, Sableye, Scizor, Excadrill | Tyranitar + Sableye                                              |
| Ninetales, no Shuckle     | Tyranitar, Sableye, Scizor, Gardevoir | Tyranitar + Sableye                                              |
| No Ninetales + Shuckle    | Sableye, Scizor, Gardevoir, Excadrill | Slaking present: Sableye + Scizor; otherwise Sableye + Gardevoir |
| No Ninetales + no Shuckle | Tyranitar, Sableye, Scizor, Gardevoir | Sableye + Scizor                                                 |

Key rules: **Sableye is mandatory if Slaking is present. Bring Excadrill if Shuckle is present, but never lead it into Shuckle.** Sableye has no Protect. Under Neutralizing Gas there is no Truant to stall—kill Weezing first. The exception is Slaking holding Ability Shield, which keeps Truant active.

## Lead 1: Tyranitar + Sableye — whenever Ninetales is in Mark's four

Exception: if you expect **Gas + Slaking on the lead**, use **Tyranitar + Gardevoir** instead. Choice Band Play Rough can OHKO Sableye before it moves; bring it after Weezing is removed.

### Turn 1

- **Tyranitar: Rock Slide**, targeting Ninetales. If Ninetales is in back, Rock Slide the active pair.
- **Sableye**, in priority order:
  1. Slaking is active, Misty Terrain is not up, and Gas is not up → **Will-O-Wisp Slaking**. Prankster makes it move first.
  2. Slaking is active and Gas is up → **do not default to WoW**. Slaking moves first and Choice Band Play Rough OHKOs Sableye; Life Orb leaves it at 8 HP. Knock Off Weezing or switch Sableye out; kill Weezing first.
  3. Shuckle is active → **Taunt Shuckle**.
  4. Amoonguss is active → **Taunt Amoonguss**.
  5. Otherwise, if Prankster is active → **Taunt** Weezing/Blissey/Ninetales, whichever is the support threat.
  6. If Neutralizing Gas is active → **Knock Off Weezing** instead of Taunting it; Sableye is slower than Weezing/Blissey without Prankster.

Tyranitar's Sand Stream already denies turn-1 Aurora Veil: sand overrides snow, or Gas suppresses both weather abilities. Don't waste Sableye's turn Taunting Ninetales just for Veil. Safety Goggles do not stop Hypnosis.

### Turn 2

- If Sableye was Encored into WoW, or Sticky Web went up: **switch Sableye →
  Excadrill**. Tyranitar keeps attacking; **Rapid Spin** on turn 3.
- If Ninetales is still alive: **Tyranitar Rock Slide Ninetales** again.
- If Ninetales fainted: **Rock Slide** Slaking/Weezing/Amoonguss, or **Fire
  Punch** Amoonguss.
- **Sableye:** if Slaking is unburned, terrain allows, and Gas is not up → **WoW Slaking**; otherwise **Taunt** Shuckle/Amoonguss/Blissey, **Recover** if damaged, or **Knock Off** Ninetales/Weezing. Sableye has no Protect; if it needs to stall, switch it out and let its partner Protect.

If Ninetales switches in later, sand does **not** reassert. **Taunt Ninetales** before it can Veil, or pivot Tyranitar out and back in to reset sand. If Gas is still up, prioritize Knocking Off Weezing and bringing Scizor in for Bullet Punch — don't rely on Prankster Taunt against Weezing/Blissey, and don't wait for a Truant turn.

## Lead 2: Sableye + Scizor — no Ninetales, Slaking present

Exception: if you expect **Gas + Slaking on the lead**, keep Sableye in back and lead **Tyranitar + Gardevoir** if Tyranitar is in the four, otherwise **Scizor + Gardevoir**. Choice Band Play Rough can OHKO Sableye; bring it after Weezing is removed.

### Turn 1

- **Sableye: Will-O-Wisp Slaking** if Misty Terrain is not up and Gas is not up. Under Gas, Slaking moves first and Choice Band Play Rough OHKOs Sableye; Life Orb leaves it at 8 HP. Do not default to WoW. Knock Off Weezing or switch Sableye out, then kill Weezing first.
- If Misty Terrain is up: **do not WoW**. Use **Knock Off Slaking** to remove Choice Band/Scarf/Life Orb, or **Taunt Amoonguss**.
- **Scizor: Bullet Punch Slaking**. If Amoonguss is on the field, expect Rage Powder to redirect Bullet Punch; that is acceptable only if Sableye is actually burning Slaking. Under Gas, target Weezing instead.
- If Slaking is in back: Sableye Taunts Amoonguss/Knocks Off Weezing; Scizor Bullet Punches Weezing or U-turns. Burn Slaking the turn it comes in, but only if Gas is gone.

### Turn 2

- **Sableye: Recover** if it took a hit; otherwise **Taunt Amoonguss/Blissey** or **Knock Off Weezing**. Sableye has no Protect; switch it out if it needs to stall.
- **Scizor: Bullet Punch Slaking** again, or **U-turn** to Gardevoir/Excadrill if Scizor is in Fire Punch danger. Never switch Scizor into Fire Punch; Tyranitar is the Fire Punch resist, Gardevoir/Sableye are the Earthquake pivots.
- If Misty Terrain is up: skip WoW, attack Slaking on its Truant turn, and remove Weezing to end the terrain.
- If Web is up and Slaking is burned: switch Sableye → Excadrill and spin.

## Lead 3: Sableye + Gardevoir — no Ninetales, no Slaking, Shuckle present

### Turn 1

- **Sableye: Taunt Shuckle**. This blocks Sticky Web/Encore and works even under Gas because Sableye 136 is faster than Shuckle 46. If Mental Herb is known, Knock Off first.
- **Gardevoir:**
  - Weezing active → **Psychic**
  - Amoonguss active → **Psychic**
  - Blissey active → **Psyshock**
  - Shuckle active → **Moonblast** or **Psychic**; don't expect a KO through Sturdy. Mold Breaker Excadrill ignores Sturdy, but Shuckle is still bulky.

### Turn 2

- If Web went up anyway (Mental Herb): **switch Sableye → Excadrill**; Gardevoir keeps attacking; **Rapid Spin** turn 3.
- If no Web: **Sableye Taunt again** or **Knock Off** Shuckle/Weezing/Blissey. Gardevoir keeps attacking. Sableye has no Protect; switch it out if it needs to stall.
- If Amoonguss tries Spore, Sableye's Safety Goggles block it for Sableye only; **Taunt Amoonguss**. Gardevoir can still be Spored.
- If Blissey Thunder Waves Gardevoir, **Taunt Blissey**; under Gas, **Knock Off Blissey** instead, since Sableye is slower.
- If Gas is active: Prankster is off. Taunt still works on Shuckle/Amoonguss, but not Weezing/Blissey. Knock Off Weezing and bring Scizor in for Bullet Punch.

## Scout checklist for game 1

- Ninetales: Snow Warning or Snow Cloak? Focus Sash or Light Clay? Hypnosis?
- Weezing: Neutralizing Gas, Levitate, or Misty Surge? Toxic Spikes?
- Amoonguss: Spore/Rage Powder? Rocky Helmet?
- Shuckle: Mental Herb? Sticky Web/Encore?
- Slaking: Choice Band/Scarf or Life Orb? Fire Punch/Earthquake/Knock Off/Play Rough?
- Tera types and who Mark saves Tera for.
- Don't Tera first unless it prevents a KO; this game is for information.
- Remember: Sableye has no Protect. Kill Gas Weezing before trusting Prankster, Technician, Sand Stream, Mold Breaker, Trace, or Truant.
